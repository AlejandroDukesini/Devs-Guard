# ISO/IEC 27001:2022 — controles del Anexo A relevantes

> **Aclaración.** ISO/IEC 27001 certifica el **sistema de gestión de
> seguridad de la información (SGSI) de una organización**, no un producto de
> software. DepGuard no está certificado y no puede estarlo por sí mismo. Este
> documento solo indica qué controles del Anexo A puede apoyar el proyecto
> (como software y como proceso de desarrollo) para una organización que
> mantenga o implante un SGSI. La certificación la emite un organismo de
> certificación acreditado tras auditar ese SGSI.

Evaluación interna a 2026-11-18.
